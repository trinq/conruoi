# 01: Project Scaffolding + Phaser Boot

**What to build:** A working Phaser.js v3 project that loads in the browser. The player opens the page and sees a blank isometric game canvas ready for gameplay. npm project is initialized with Phaser as dependency, HTML entry point serves the game, BootScene preloads a placeholder asset, and GameScene renders an empty isometric-tinted background.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] npm project initialized with package.json and Phaser.js v3 as dependency
- [ ] HTML entry point (index.html) loads the Phaser game with correct canvas dimensions
- [ ] Phaser game config uses WebGL with Canvas fallback
- [ ] BootScene preloads at least one placeholder asset and transitions to GameScene
- [ ] GameScene renders a visible background with isometric-style coloring
- [ ] Game runs with `npm run dev` or equivalent dev server and displays in browser
